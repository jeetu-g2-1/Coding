# 🧩 1. Decorators in Python

## 📌 Definition:
A **decorator** is a function that modifies the behavior of another function without changing its code.  
It’s a powerful tool in Python for:
- Code reuse
- Logging
- Timing
- Authentication

# ⚙️ 2. Generators in Python

## 📌 Definition:
A **generator** is a function that returns an **iterator** and yields values **one at a time** using the `yield` keyword.  
Generators are **memory-efficient** for working with large sequences.
